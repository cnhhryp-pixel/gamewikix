Use it as a challenge tool

The generator is intentionally game-agnostic. Replace the default pool with weapons, characters, roles, classes, perks or self-imposed rules from the game you are playing.

For a fairer challenge, keep options at a similar power level. For a chaos run, mix strong, weak and utility-only choices in the same pool.
