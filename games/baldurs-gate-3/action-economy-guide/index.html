Baldur's Gate 3 Action Economy Guide

A Baldur's Gate 3 action economy guide for getting more value from actions, bonus actions, movement and control each turn.

Every turn has limited opportunities

Combat becomes easier when each character uses their available action, bonus action and movement toward a clear purpose.

High-impact actions change the board

Damage is useful, but control, repositioning and denying enemy actions can create more total value than a small attack.

Movement is part of the turn

Good movement improves range, line of sight, safety and future options. Do not treat it as separate from the action plan.

Remove enemy turns when possible

Defeating, disabling or isolating an enemy reduces the number of actions the opposing side can take on later turns.
